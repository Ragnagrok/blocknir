Ragnagrok Engine

A small voxel engine for the web, with a browser editor and synthesized audio. No image or sound files needed.

EditorPaint models, rig and animate figures, lay out scenes with fixed cameras. AdventureA minimal fixed-camera adventure that plays the editor's project. RoomThe smallest example: a diorama built in code.

What's inside

  • Voxel models with ambient occlusion, glowing colors and cheap instancing.
  • Rigged figures animated with keyframe clips.
  • Scenes with fixed cameras, flickering lights, fog, doors, items and walkable heightmaps with pathfinding.
  • Synthesized audio: thirteen instruments, a step sequencer, footsteps, UI sounds and ambience.
  • Game kit: touch joystick, typewriter dialogue, async cutscenes, save slots.

Use it

npm install three github:Ragnagrok/ragnagrok-engine
